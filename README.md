An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI — every trophy with a cited guide in the author's own words, a checklist that saves in the browser, per-trophy counters, a spoiler setting, a roadmap to the platinum, and a missable timeline. Post-release research resolves In The Beginning… (Ocean View Rooftop Bar, Apple Martini); Bad Luck, I Guess and Ten Pin are honestly marked unconfirmed, with the best lead available.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network needed.
